# GNFS Crypto Attacker Simulator 🚀

Реализация высокопроизводительного многопоточного симулятора конвейера атаки **GNFS (General Number Field Sieve — Общий метод решета числового поля)** на чистом Python без использования сторонних тяжелых библиотек. Предназначен для исследования пределов классической факторизации чисел произвольной точности (**до 300+ десятичных символов / ~1024 бит**).

## 🪐 Ключевые особенности и оптимизации

*   **Многопоточный движок просеивания (Sieving):** Распределение вычислений полиномиальных норм по координатной решетке (a, b) с использованием асинхронного пула процессов `multiprocessing.Pool` (автоматическое масштабирование под все доступные ядра CPU).
*   **Чисто целочисленная арифметика (`BigInt`):** Извлечение корней высоких степеней и построение зацепления полей реализовано через бинарный поиск и метод Ньютона, что полностью исключает падения по аппаратному переполнению `OverflowError` (лимит стандартного `float` в 10³⁰⁸).
*   **Побитовый редуктор Гаусса над полем GF(2):** Поиск линейных зависимостей (масок четности экспонент) реализован с помощью быстрых логических побитовых масок (`<<`, `^`, `&`), что предотвращает накладные расходы на обход вложенных списков и гарантирует стабильность по индексам (`IndexError`).
*   **Смягченный фильтр отбора (Relaxed Large Prime Variation):** Адаптивная генерация масок предотвращает разреженность матриц на демонстрационных базах факторов при работе со сверхбольшими нормами.

## 🛠 Быстрый запуск

Для запуска конвейера требуется только установленный интерпретатор **Python 3.x**:

```bash
python3 gnfs.py
```
